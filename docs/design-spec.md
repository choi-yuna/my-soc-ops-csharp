# Princess Theme Design Spec

## Overview
Transforming the SocOps Blazor bingo game into a magical princess-themed design with elegant, distinctive aesthetics.

## Color Palette
- **Primary**: Pink (#ec4899) - Main accent color
- **Secondary**: Purple (#9333ea) - Royal purple for accents
- **Winning**: Gold (#fbbf24) - Triumphant gold for victories
- **Backgrounds**: Soft pink pastels (#fdf2f8) - Gentle, magical base

## Typography
- **Titles**: Playfair Display (clean modern serif)
- **Body**: System fonts with high contrast
- **Accessibility**: Maintain WCAG compliance

## Decorative Elements
- Sparkles and subtle gradients
- Elegant borders and shadows
- Crown icon for winning modal
- Smooth animations and transitions

## Component Updates
1. **app.css** - Core color variables and fonts
2. **StartScreen.razor** - Pink gradients, rounded design
3. **GameScreen.razor** - Header and background styling
4. **BingoSquare.razor** - Ornate borders, hover effects
5. **BingoModal.razor** - Crown theme, princess messaging
6. **MainLayout.razor.css** - Royal purple sidebar

## Implementation Notes
- Use CSS variables for consistency
- Add motion/animations for delight
- Maintain all functionality
- Ensure accessibility and high contrast
- Keep design simple yet elegant
